# DocCnt Class Implementation

## Overview

The `DocCnt` class is a record-like data structure that pairs a `Doc` object with an integer count. It implements the Comparable interface through Python's comparison operators, allowing DocCnt objects to be sorted and compared based on their count values.

## Purpose

`DocCnt` is designed for scenarios where documents need to be ranked or ordered by a numeric value, such as:
- Search result ranking by keyword match count
- Document relevance scoring
- Frequency-based sorting
- Any application requiring document-count pairs

## Class Definition

```python
from functools import total_ordering
from doc import Doc

@total_ordering
class DocCnt:
    """
    Overview: DocCnt is a record-like type with two fields: a Doc and an integer count.
    
    The class implements comparison based on the count value, allowing DocCnt objects
    to be sorted and compared.
    """
```

## Constructor

### `__init__(doc: Doc, cnt: int)`

Initialize a DocCnt with a document and count.

**Parameters:**
- `doc` (Doc): The Doc object to associate with this count
- `cnt` (int): The count value (can be positive, negative, or zero)

**Raises:**
- `ValueError`: If doc is None
- `TypeError`: If doc is not a Doc instance
- `TypeError`: If cnt is not an integer

**Example:**
```python
doc = Doc.from_string("Python Tutorial\nLearn Python basics")
doc_cnt = DocCnt(doc, 15)  # Document with count of 15
```

## Properties

### `doc` (read-only)

Returns the Doc object associated with this DocCnt.

**Returns:** `Doc` - The document

**Example:**
```python
doc_cnt = DocCnt(my_doc, 5)
document = doc_cnt.doc  # Access the document
title = doc_cnt.doc._title
```

### `cnt` (read-only)

Returns the count value.

**Returns:** `int` - The count

**Example:**
```python
doc_cnt = DocCnt(my_doc, 10)
count = doc_cnt.cnt  # Returns 10
```

## Comparison Methods

The class uses Python's `@total_ordering` decorator, which automatically generates all comparison operators from `__eq__` and `__lt__`.

### `__eq__(other) -> bool`

Check if two DocCnt objects have equal counts.

**Effects:**
- If other is None, raises TypeError
- If other is not a DocCnt, raises TypeError
- Otherwise, returns True if counts are equal

**Example:**
```python
dc1 = DocCnt(doc1, 5)
dc2 = DocCnt(doc2, 5)
dc1 == dc2  # True (same count)
```

### `__lt__(other) -> bool`

Check if this DocCnt has a smaller count than another.

**Effects:**
- If other is None, raises TypeError
- If other is not a DocCnt, raises TypeError
- Otherwise, returns True if this.cnt < other.cnt

**Example:**
```python
dc1 = DocCnt(doc1, 3)
dc2 = DocCnt(doc2, 7)
dc1 < dc2  # True (3 < 7)
```

### Other Comparisons (auto-generated by @total_ordering)

The following operators are automatically provided:
- `>` (greater than)
- `<=` (less than or equal)
- `>=` (greater than or equal)
- `!=` (not equal)

**Example:**
```python
dc1 = DocCnt(doc1, 5)
dc2 = DocCnt(doc2, 10)

dc2 > dc1   # True
dc1 <= dc2  # True
dc1 != dc2  # True
```

## Sorting

DocCnt objects can be sorted using Python's built-in sorting functions. Sorting is based on the count value.

**Example:**
```python
dc1 = DocCnt(doc1, 15)
dc2 = DocCnt(doc2, 5)
dc3 = DocCnt(doc3, 10)

doc_cnts = [dc1, dc2, dc3]

# Sort ascending (lowest count first)
sorted_asc = sorted(doc_cnts)
# Result: [dc2 (5), dc3 (10), dc1 (15)]

# Sort descending (highest count first)
sorted_desc = sorted(doc_cnts, reverse=True)
# Result: [dc1 (15), dc3 (10), dc2 (5)]

# Find min and max
min_doc = min(doc_cnts)  # dc2 with count 5
max_doc = max(doc_cnts)  # dc1 with count 15
```

## Usage Examples

### Example 1: Search Result Ranking

```python
from docCnt import DocCnt
from doc import Doc

# Create documents with match counts
doc1 = Doc.from_string("Python Tutorial\nLearn Python programming")
doc2 = Doc.from_string("Advanced Python\nAdvanced Python topics")
doc3 = Doc.from_string("Python Basics\nGetting started with Python")

# Create DocCnt objects with keyword match counts
results = [
    DocCnt(doc1, 8),   # 8 keyword matches
    DocCnt(doc2, 15),  # 15 keyword matches
    DocCnt(doc3, 5),   # 5 keyword matches
]

# Rank by relevance (highest count first)
ranked = sorted(results, reverse=True)

for rank, dc in enumerate(ranked, 1):
    print(f"{rank}. {dc.doc._title} (matches: {dc.cnt})")
# Output:
# 1. Advanced Python (matches: 15)
# 2. Python Tutorial (matches: 8)
# 3. Python Basics (matches: 5)
```

### Example 2: Filter and Sort

```python
# Create a collection of document-count pairs
doc_cnts = [
    DocCnt(doc1, 3),
    DocCnt(doc2, 15),
    DocCnt(doc3, 7),
    DocCnt(doc4, 10),
    DocCnt(doc5, 2),
]

# Filter documents with count >= 5
relevant = [dc for dc in doc_cnts if dc.cnt >= 5]

# Sort by relevance
ranked = sorted(relevant, reverse=True)

# Get top 3
top_3 = ranked[:3]
```

### Example 3: Comparison Logic

```python
dc1 = DocCnt(doc1, 10)
dc2 = DocCnt(doc2, 10)
dc3 = DocCnt(doc3, 5)

# Equality comparison (based on count only)
if dc1 == dc2:
    print("Same relevance score")

# Order comparison
if dc1 > dc3:
    print(f"{dc1.doc._title} is more relevant than {dc3.doc._title}")
```

## Error Handling

The class performs strict type checking and validation:

```python
# ValueError: Doc cannot be None
try:
    dc = DocCnt(None, 5)
except ValueError as e:
    print(f"Error: {e}")

# TypeError: doc must be a Doc instance
try:
    dc = DocCnt("not a doc", 5)
except TypeError as e:
    print(f"Error: {e}")

# TypeError: cnt must be an integer
try:
    dc = DocCnt(doc, "5")
except TypeError as e:
    print(f"Error: {e}")

# TypeError: Cannot compare with None
try:
    result = dc == None
except TypeError as e:
    print(f"Error: {e}")

# TypeError: Can only compare DocCnt with DocCnt
try:
    result = dc < 10
except TypeError as e:
    print(f"Error: {e}")
```

DocCnt supports zero and negative counts:


### Large Counts

DocCnt handles arbitrarily large integer counts:

```python

```

## Implementation Details

### Design Decisions

1. **@total_ordering Decorator**: Uses Python's functools to automatically generate all comparison methods from `__eq__` and `__lt__`, reducing code duplication.

2. **Immutable Fields**: Properties are read-only (no setters), making DocCnt objects effectively immutable after creation.

3. **Strict Type Checking**: Constructor validates types to prevent runtime errors and ensure type safety.

4. **Comparison by Count Only**: Two DocCnt objects are equal if their counts are equal, regardless of the Doc content.

### Comparison with Java Comparable

The Python implementation follows the specification's Java-like design:

| Java (Specification) | Python (Implementation) |
|---------------------|------------------------|
| `implements Comparable` | `@total_ordering` decorator |
| `int compareTo(Object x)` | `__lt__` and `__eq__` methods |
| Returns -1/0/1 | Returns boolean |
| `throws NullPointerException` | Raises `TypeError` |
| `throws ClassCastException` | Raises `TypeError` |
